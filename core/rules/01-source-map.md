# 检索源地图

按游戏形态给出应优先检索的站点。**优先原始出处，聚合站只用来顺藤摸瓜。**

## 通用优先级

`官方公告 / 官方wiki` > `大型社区wiki` > `头部创作者实测` > `社区讨论` > `视频` > `聚合站（仅索引用）`

---

## 一、网络游戏（MMO / 竞技 / 赛季制客户端）

| 类型 | 站点 | 说明 |
|------|------|------|
| 官方 | 游戏官网公告、官方公众号、官方微博 | 版本更新、活动、数值调整的一手来源 |
| 社区wiki | BWiki（bilibili game wiki）、Fandom、灰机wiki、萌娘百科 | 条目全、更新快，附图片与数据表 |
| 社区讨论 | NGA、百度贴吧、Reddit（r/ 对应分区）、Discord | 边界情况、BUG、玩家实测反馈 |
| 数据库 | 各游戏专用数据库站（如 wowhead 类、lor 类） | 掉落、掉率、坐标、任务链 |
| 视频 | B 站、YouTube | 实战演示，抓简介与时间轴 |

时效敏感度：**高**。赛季/版本一变，旧攻略即废。

## 二、单机 / 主机游戏

| 类型 | 站点 | 说明 |
|------|------|------|
| 官方 | 官网、官方社媒、Steam 新闻页 | 补丁说明、DLC 内容 |
| 社区wiki | Fandom、灰机wiki、BWiki、中文专项wiki | 任务链、收集品、结局条件 |
| 中文攻略 | 游民星空、3DM、游侠网、A9VG、电玩巴士 | 中文流程攻略、图文路线 |
| 英文/日文 | IGN、GameSpot、PCGamingWiki、GameWith、Gamerch、Famitsu | 外服细节、隐藏要素、日文原名检索 |
| 视频 | B 站、YouTube | 难点演示、速通路线 |
| 其他 | Steam 社区指南、SteamDB、PCGamingWiki（修复/设置类） | 报错、闪退、配置问题 |

时效敏感度：**中**。补丁与 DLC 会改机制，发售后越久越稳定。

## 三、手机游戏

| 类型 | 站点 | 说明 |
|------|------|------|
| 官方 | 官网公告、官方社媒、游戏内公告 | 版本更新、卡池、活动 |
| 社区wiki | BWiki、Fandom、灰机wiki、萌娘百科 | 角色数据、配装、圣遗物/词条 |
| 玩家社区 | TapTap、好游快爆、NGA 手游区、贴吧、小黑盒 | 配队讨论、实测、避坑 |
| 内容平台 | B 站专栏/视频、小红书、抖音 | 图文速查、配装一图流 |
| 外服 | GameWith、Game8、Altema、Dot GG、Reddit | 国际服/日服先于国服的版本信息 |

时效敏感度：**高**。数值与卡池每版本变动，国服与国际服进度不同需区分。

## 四、微信 / 抖音小游戏

| 类型 | 站点 | 说明 |
|------|------|------|
| 平台内 | 小游戏内公告、排行榜、官方小程序 | 关卡机制、活动 |
| 社区 | 贴吧、小红书、抖音评论区、B 站 | 通关技巧、卡关讨论 |
| 聚合 | 各类小游戏攻略站、公众号 | 关卡图解，注意甄别过时版本 |
| 视频 | 抖音、B 站、快手 | 实操演示，抓步骤 |

时效敏感度：**低到中**，但**换皮与多版本分叉严重**——同名小游戏可能存在多个版本或平台移植版，机制不同，必须确认来源对应的是同一个版本。

## 五、页游 / 其他

优先官方公告 + 贴吧 + 老牌攻略站；注意大量聚合站内容为机器采集，需回溯原帖。

---

## 检索入口技巧

- 站内搜索优先于通用搜索：`site:<域名> <关键词>`（部分搜索引擎支持）
- 用**游戏内原名**而非译名检索外服内容：如 "原神" → "Genshin Impact"、"原神 稲妻" → "Genshin Inazuma"
- 日文游戏用日文原名检索命中率最高：如 "ELDEN RING" → "エルデンリング"
- wiki 站通常有英文/中文/日文多语版本，切换语种可互补缺失条目
