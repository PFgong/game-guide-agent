# 检索打法

## 一、关键词构造

### 组合公式
```
<游戏全名> + <具体对象> + <意图词>
```

意图词库：
- 触发类：触发条件、怎么触发、前置任务、解锁方法、how to unlock / trigger / spawn
- 打法类：打法、攻略、阵容、站位、无敌帧、怎么打、boss fight / strategy / guide
- 配装类：配装、配队、圣遗物、词条、加点、毕业、best build / team comp / artifacts
- 资源类：在哪刷、掉落点、获取方式、最快、location / farm / drop rate
- 机制类：机制、公式、概率、隐藏、mechanic / formula / hidden
- 流程类：全收集、100%、路线、速通、walkthrough / route / speedrun
- 报错类：报错、进不去、闪退、卡死、error / crash / stuck

### 三语对照
- 中文：用于国产游戏与中文社区，命中率最高
- 英文：用于欧美游戏与国际服，交叉验证
- 日文：日系游戏**必查**，日文社区（GameWith / Altema / Gamerch）常有中文社区还没有的细节

## 二、检索批次

1. **批次一（中文）**：`游戏名 + 对象 + 意图词`，跑 2-3 种问法
2. **批次二（外服）**：英文名 / 日文名 + 对应意图词
3. **批次三（定向）**：进入 01-source-map.md 对应站点做站内搜索
4. **批次四（补缺）**：视频平台抓实操，社区抓边界情况

## 三、失败降级路径

| 症状 | 动作 |
|------|------|
| 零结果 | 检查游戏名是否用了简称/错字 → 换官方全名 → 换英文名 |
| 结果全是聚合站 | 从聚合站正文里找它引用的原帖标题 → 直接搜原帖标题 |
| 结果全是旧版本 | 加版本号/赛季号重搜 → 查官方更新日志确认机制是否已改 |
| 只有视频无文字 | 抓视频标题 + 简介 + 分P + 高赞评论，转成文字步骤 |
| 需要登录/JS 渲染 | 改用 `agent-browser` skill 打开页面取内容 |
| 反爬/403 | 换镜像站、换语种站、换同类竞品站、用缓存页 |
| 中日英都查不到 | 判定为**缺口**，不要编造；在答案中说明"该信息当前无可靠公开来源" |

## 四、图片抓取

### 要抓什么
地图位置标注图、路线示意图、装备/面板配置截图、站位图、数值对比表、掉落位置标记

### 直链判定
- ✅ 以 `http(s)://` 开头、URL 路径以 `.png/.jpg/.jpeg/.webp/.gif` 结尾或明确指向图片资源
- ✅ wiki 站图床、攻略站图床、官方 CDN
- ❌ 搜索引擎缩略图地址（通常带 `encrypted-tbn` 或尺寸参数）
- ❌ 需要 Referer 才能加载的防盗链图
- ❌ 验证码图、广告图、与内容无关的头图

### 记录格式
| 内容说明 | 图片直链 | 来源页 URL | 站点 |

一个答案 2-5 张图足够，宁缺毋滥。

## 五、抓取工具选择

| 场景 | 工具 |
|------|------|
| 快速找候选来源 | WebSearch |
| 抓静态正文 | WebFetch |
| 登录墙 / JS 渲染 / 翻页 / 需要交互 | `agent-browser` skill |
| 确认官方更新日志 | WebSearch + WebFetch（定向到官网/社媒） |
