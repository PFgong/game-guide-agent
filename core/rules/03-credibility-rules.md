# 可信度与时效核验规则

## 一、来源可信度分级

| 级别 | 来源类型 | 采信方式 |
|------|---------|---------|
| S | 官方公告、官方 wiki、游戏内文本 | 直接采信，可作仲裁依据 |
| A | 大型社区 wiki（BWiki / Fandom / 灰机 / GameWith / Altema） | 直接采信，但需确认条目更新时间 |
| B | 头部创作者实测（有截图/视频/数据支撑） | 采信，关键数值需二次来源佐证 |
| C | 社区讨论（NGA / 贴吧 / Reddit / TapTap） | 仅作补充与边界情况，孤证不采信 |
| D | 聚合站、采集站、无署名内容农场 | **不采信**，仅用于顺藤摸瓜找原帖 |

## 二、时效判定流程

```
证据是否标注版本/时间？
├─ 否 → 标"时间未知" → 需 ≥1 个 A 级以上近期来源佐证，否则判 🟡
└─ 是 → 与 Brief 的版本锚点比对
        ├─ 版本一致 → 采信
        ├─ 版本落后 → 查官方更新日志/补丁说明
        │             ├─ 相关机制未改 → 采信，标注"适用于 <旧版本> 至今"
        │             ├─ 相关机制已改 → 判失效，剔除
        │             └─ 无法确认 → 判 🟡，答案中标注需玩家确认
        └─ 版本超前（测试服/外服先行）→ 标注"国服尚未实装"
```

### 时效敏感度基线
| 游戏形态 | 敏感度 | 说明 |
|---------|--------|------|
| 网游（赛季制） | 高 | 赛季更新即作废，超 1 个赛季的证据默认不可用 |
| 手游 | 高 | 数值/卡池每版本变动；注意国服与国际服进度差 |
| 单机（新发售 6 个月内） | 高 | 补丁频繁 |
| 单机（发售多年无更新） | 低 | 旧攻略通常仍有效 |
| 小游戏 | 低~中 | 但换皮/多版本分叉严重，必须确认版本一致 |

## 三、伪攻略识别清单

命中 2 条以上即降级，命中 3 条以上直接剔除：

- [ ] 通篇正确废话，无任何具体数值、坐标、名称
- [ ] 步骤含糊到无法执行（"注意走位""多练练""找准时机"）
- [ ] 数据与官方公开数据矛盾
- [ ] 无版本说明、无截图、无实测细节（疑似 AI 批量生成）
- [ ] 标题党（"99% 的人不知道""最强！""一招秒杀"）但内容空洞
- [ ] 通篇搬运自另一篇且丢失了关键限定条件
- [ ] 发布时间与所描述的游戏状态明显不符（如描述的内容当时尚未实装）

## 四、数值自洽性检查

| 检查项 | 判废条件 |
|--------|---------|
| 掉率 / 概率 | > 100% 或为负；与官方公布值差异 > 一个数量级 |
| 伤害 / 加成 | 与同类来源差异 > 30% 且无解释 |
| 坐标 | 与地图描述矛盾，或超出地图边界 |
| 消耗 / 产出 | 与游戏内经济系统明显冲突 |
| 时间 / 冷却 | 违反同类机制的通用量级 |

多源数值不一致时：**保留各方数值 + 出处**，在答案中以"说法不一"标注，不强行取一个。

## 五、冲突仲裁优先级

```
官方 > 大型wiki > 头部创作者实测 > 社区讨论 > 聚合站
同级冲突 → 取更新时间更新的一方
同级同时 → 保留分歧，标 🟡
```

## 六、不可采信内容（红线）

以下内容一律不进答案，并在风险提示中标明：

- 外挂、脚本、加速器、代练、代肝
- 刷初始号、买卖账号、利用 BUG 刷资源/货币
- 修改器、存档篡改（单机可酌情说明存在，但不给具体获取渠道）
- 任何涉及账号封禁风险的操作
- 需要用户提供账号密码、支付信息的第三方站点

## 七、置信度分级

| 等级 | 判定条件 | 答案中的处理 |
|------|---------|-------------|
| 🟢 高 | ≥2 个独立来源一致 且 版本匹配 | 正常输出 |
| 🟡 中 | 单一 A 级以上来源；或多源一致但版本未明 | 输出 + 一行版本提示 |
| 🔴 存疑 | 来源冲突 / 版本过期且无法确认 / 仅 C 级孤证 | 输出 + 明确标注分歧与不确定性，或建议玩家实测确认 |
