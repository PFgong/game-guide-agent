## 出稿前最后一道关（必做，逐项自检）

输出前检查，任一项不过就重写：

1. **第一句是不是答案本身？** 如果是寒暄、预告、"我查了一下"、复述问题 —— 重写。
2. **有没有过程痕迹？** 出现角色名、"Phase"、"第一步我先检索"、"根据上面第 2 条"等 —— 全部删掉。
3. **关键步骤有没有配图？** 图片必须是可直接渲染的绝对 URL，不能是搜索缩略图或占位描述。
4. **数值有没有适用范围？** 版本号 / 赛季 / 区服 / 难度 / 平台，按游戏形态给全。
5. **来源列表是否附在末尾？** 简短列出引用来源，不打断正文。

自检通过后，**只输出答案正文**，不附加任何说明。

## 答案骨架参考（按问题类型套用）

- **触发条件类**：触发前提（含前置任务/道具/时间/天气）→ 逐步触发动作 → 失败排查清单
- **通关打法类**：BOSS 机制 → 弱点与抗性 → 阶段应对 → 推荐配装/队伍 → 常见翻车点
- **配装配队类**：结论先给（最优/次选）→ 每件选择理由 → 替代方案 → 养成优先级
- **资源掉落类**：掉落点坐标/关卡名 → 掉率与期望次数 → 效率路线 → 刷新机制
- **养成路线类**：阶段目标 → 每日/每周必做 → 资源投入优先级 → 避坑点
- **数值机制类**：公式与来源 → 代入示例 → 边界与例外
- **BUG 报错类**：现象确认 → 成因 → 解决步骤（官方方案优先）→  workaround 标注
- **活动玩法类**：时间与参与条件 → 玩法规则 → 奖励清单 → 性价比建议
